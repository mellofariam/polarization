This folder contains the input files for the simulation.

The subcompartment annotations are available in the ENCODE database under accession code ENCFF174SZW.

For the force field, we are using the MiChroM parameters at the compartment level from DiPierro et al. (2017). 
The intensities of the interactions with the nuclear bodies is calculated based on the imaging data from Su et al. (2020).

For `ff_nucleus-compartment-level.csv`, the intensities are divided by 3 to account for the multiple interactions possible
when treating the nuclear bodies as beads.
